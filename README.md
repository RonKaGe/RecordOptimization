# RecordOptimization

## PostgreSQL

Создайте пустую базу PostgreSQL 18 и выполните [db/schema.sql](db/schema.sql). Для установки расширения btree_gist потребуется роль с соответствующими правами.

В pgAdmin откройте Query Tool для новой базы, загрузите schema.sql и выполните скрипт целиком. Он создаст 13 таблиц. Используйте этот файл для первоначального развёртывания пустой базы.
