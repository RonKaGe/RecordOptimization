# RecordOptimization

## PostgreSQL

Создайте пустую базу PostgreSQL 18 и выполните [db/schema.sql](db/schema.sql). Для установки расширения btree_gist потребуется роль с соответствующими правами.

В pgAdmin откройте Query Tool для новой базы, загрузите schema.sql и выполните скрипт целиком. Он создаст 13 таблиц. Используйте этот файл для первоначального развёртывания пустой базы.

## Запись клиентов

Для временной брони создайте запись со статусом reserved. PostgreSQL выставит reserved_until на 10 минут вперёд. До истечения срока запись можно подтвердить, указав имя и телефон клиента. Для расчёта доступности используйте active_booking_intervals: представление учитывает подтверждённые записи и действующие брони.

В booking_sources хранятся общие источники phone, qr, website и app. Свои варианты привязываются к организации через organization_id. В services.price хранится цена в целых рублях.
